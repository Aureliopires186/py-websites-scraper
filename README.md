## O que é
Este projeto mostra como fazer scraping de sites do Google usando SerpApi em Go.
Sem precisar de proxy, sem ser bloqueado.

## Como usar
1. Crie conta em https://serpapi.com
2. Exporte sua API Key: `export SERPAPI_KEY=sua_chave_aqui`
3. Rode: `go run main.go`

## Exemplos incluídos
- `google_jobs.go` - Vagas de emprego
- `google_shopping.go` - Produtos
- `google_news.go` - Notícias

## Por que SerpApi?
APIs previsíveis, documentação top e dados estruturados. Ideal pra devs.
